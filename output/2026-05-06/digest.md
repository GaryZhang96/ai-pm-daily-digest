## 1. 底层更新
### Anthropic Engineering: Claude Code auto mode: a safer way to skip permissions
Anthropic公司推出了Claude Code的auto模式，这是一种新的执行模式，旨在减少用户在命令执行或文件修改时的权限确认次数。该模式通过基于模型的分类器来代理审批流程，目标是在保持高自主性的同时降低维护成本，并随着分类器覆盖范围和模型判断的改善提高安全性。Claude Code auto模式通过输入层和输出层的两层防御机制来工作，前者用于扫描工具输出，后者则在执行前评估每个动作是否符合决策标准。[阅读更多](https://www.anthropic.com/engineering/claude-code-auto-mode)
